# Space Invader C++ Game

## Overview

This repository contains a simple Space Invader-style game developed in C++.

The project was created to practice object-oriented programming, game logic, user input handling, and basic collision detection.

## Features

- Player movement
- Enemy movement
- Shooting mechanics
- Collision detection
- Score tracking
- Basic game loop

## Tech Stack

- C++
- Object-Oriented Programming
- Console-based game logic / graphics library, update this section if used
- GCC / MinGW / Visual Studio
